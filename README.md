# Digital Signal Processing (DSP) Assignments – MATLAB

This repository contains a collection of **Digital Signal Processing (DSP)** assignments implemented in **MATLAB** as part of a university/lecture course.

The projects focus on fundamental DSP concepts such as:
- FIR filter design
- Fourier Transform analysis
- DFT (Discrete Fourier Transform)
- Windowing methods
- Frequency sampling techniques
- Signal transformations and spectral analysis

---

## Repository Contents

### Core Assignments

#### 1. DFT and Single-Sided Power Spectrum
**File:** `DFT and single sided power spectrum.m`  
Implements Discrete Fourier Transform and computes the **single-sided power spectrum** of a signal.

---

#### 2. FIR Filter Design (Basic)
**File:** `FIR filter.m`  
Basic implementation of an FIR filter structure and filtering operation.

---

#### 3. FIR Filter – Window Function Method
**File:** `FIR filter window func.m`  
Design of FIR filters using **windowing techniques** (e.g., Hamming, Hanning, Rectangular windows).

---

#### 4. FIR Filter – Fourier Transform Method
**File:** `FIR filter Fourier Transform.m`  
FIR filter design using the **frequency-domain (Fourier Transform) approach**.

---

#### 5. FIR Filter – Frequency Sampling Method
**File:** `FIR filter Frequency Sampling Method.m`  
Implements FIR filter design using the **frequency sampling technique**.

---

#### 6. Impulse Response of Z-Transformed Sinusoid
**File:** `Impulse-response of Z Transformed sinusoid.m`  
Analyzes the impulse response of a signal using **Z-transform concepts**.

---
